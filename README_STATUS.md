# 💎 Obsidian Retail: Technical Brief & Status

## 🚀 Overview
Obsidian Retail is a high-end, AI-powered e-commerce infrastructure designed for Nigerian social commerce. It allows merchants to turn their Instagram/WhatsApp feeds into a professional, high-conversion storefront in seconds.

## 🏗️ Technical Architecture
- **Frontend**: Next.js 14 (App Router) with a premium "Anti-AI" aesthetic.
- **Logic**: TypeScript with Framer Motion for buttery-smooth interactions.
- **Database**: Supabase (PostgreSQL) with real-time listeners.
- **Storage**: Supabase Storage for high-fidelity product imagery.
- **Payments**: Payaza Integration (Virtual Accounts & Webhooks).
- **AI Engine**: Dual-provider setup (GPT-4o & Gemini 1.5 Flash) for catalog parsing.
- **Ingestion**: Playwright-based browser automation for social media scraping.

## 🧠 Smart Ingest Pipeline
1. **Targeting**: Accepts Instagram Profile URLs or individual post links.
2. **Scanning**: Launches a masked mobile browser (iPhone 15 identity) to bypass social media security.
3. **Extraction**: Captures high-res images and raw captions via dynamic DOM traversal.
4. **AI Parsing**: AI "sees" the image and "reads" the caption to extract metadata.

## ⚠️ Current Technical Challenges
- **Instagram Security**: Instagram frequently blocks bots with "Login Walls" or Captchas.
- **Hosting**: Playwright requires a local browser environment (Desktop) and cannot run on standard Vercel serverless functions.
- **Remedy**: Use the **Manual Image Upload** for 100% reliable live demos.
